# ApexCloud Technologies - Pricing & Subscription Plans

## Overview
ApexCloud is an intelligent enterprise cloud collaboration and workflow automation platform. We provide four transparent pricing tiers tailored to growing teams and global organizations.

## Plan Comparison Matrix

### 1. Starter Tier (Free)
- Price: $0 / month forever
- Users: Up to 3 team members
- Storage: 10 GB secure cloud storage
- Features: Basic workflow boards, community forum support, standard SSL encryption.
- Limitations: No API access, no custom domain, no phone or live chat support.

### 2. Professional Tier (Pro)
- Price: $29 per user / month (or $24 per user / month billed annually - save 17%)
- Users: 4 to 25 team members
- Storage: 500 GB pooled storage
- Features: Real-time document collaboration, unlimited workflow automation pipelines, REST API access (rate limit 1,000 requests/minute), 99.9% uptime SLA.
- Support: Standard email and live chatbot support with a guaranteed 12-hour response time.

### 3. Business Tier
- Price: $79 per user / month (or $65 per user / month billed annually - save 18%)
- Users: 26 to 100 team members
- Storage: 2 TB high-speed cloud storage
- Features: Advanced analytics and audit logs, Single Sign-On (SSO via Okta, Google Workspace, Azure AD), custom branding, unlimited integrations.
- Support: Priority email and live chat support with a guaranteed 2-hour response time during business hours.

### 4. Enterprise Tier
- Price: $199 per user / month (minimum 50 seats, billed annually)
- Users: Unlimited team members
- Storage: Unlimited distributed storage
- Features: Dedicated private cloud instance, custom data residency (US, EU, APAC), 99.99% financially backed uptime SLA, customized security controls.
- Support: 24/7/365 dedicated Technical Account Manager (TAM), direct phone access, 15-minute response time SLA for critical incidents.

## Payment Methods & Currencies
ApexCloud accepts all major credit cards (Visa, MasterCard, American Express), PayPal, ACH wire transfers (for annual plans exceeding $5,000), and purchase orders. We bill in USD, EUR, GBP, and INR.
